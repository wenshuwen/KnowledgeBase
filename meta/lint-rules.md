# Lint 规则清单

> 每周自动体检按本清单执行。**分两类输出**：能自动修的直接修并记日志；需要判断的列成待确认清单交给人。

## A. 结构类（通常可自动修）

| 编号 | 检查项 | 判定方式 | 处理 |
|---|---|---|---|
| A1 | frontmatter 缺字段 | 缺 `type`/`updated`/`tags` 任一 | 自动补，`type` 不确定则列出 |
| A2 | `sources` 指向不存在的文件 | 路径不可达 | 列出待确认 |
| A3 | 标签不在体系内 | 不在 WIKI-SCHEMA 第 4 节清单 | 建议最接近的既有标签 |
| A4 | 标签同义分叉 | 编辑距离近 / 人工维护同义词表 | 合并，记日志 |
| A5 | 文件名不合法 | 含 `/ \ : * ? " < > \|` | 自动重命名并修全库链接 |
| A6 | 缺 `## 相关` 段或出链 < 2 | 解析页面。**判「缺段」必须锚行首**（`^##\s*相关`），不得用子串匹配——正文里引用「`## 相关`」四个字会造成漏报（2026-10-12 实例：体检报告页谈地图缺省回链时引用了该字样，致连续两周漏判） | 缺段则直接补 `## 相关` + ≥2 条出链；出链不足提出补链建议 |
| A7 | **死链**：`[[链接]]` 指向不存在的页面 | 链接名不在全库文件名集合中 | 修正链接名，或补建目标页；**代码块内的示例写法要排除** |
| A8 | **问答沉淀索引页命名错误** | `wiki/76-问答沉淀/` 下的索引页被命名为 `index.md` | 改名为 `问答沉淀索引.md`，并修正全库对它的引用。`build_kb.py` 的 `SKIP_FILENAMES`（`{index.md, log.md}`）会**静默跳过**它，导致该目录所有条目在站点上变成点不通的孤页 |
| A9 | **两套 cat 词汇混用** | wiki 页 frontmatter 的 `interview.cat` 写成归档**短键**（`api`/`perf`/`auto`/`sec`/`ai`/`llm`/`agent`/`aitools`/`env`/`db`/`scene`/`devops`/`soft`/`python`/`theory`，唯一定义在 `site/tools/archive.py` 的 `SITE_CATS`） | 按 WIKI-SCHEMA §8.2 的映射表改回**长键**（`api-testing`…）。反向也要查：归档条目误用长键 → 交每日任务修，不在本任务直接改归档 |

## B. 内容类（必须人工确认）

| 编号 | 检查项 | 判定方式 | 处理 |
|---|---|---|---|
| B1 | **孤页** | 全库无入链 | 提候选父页，或建议并入他页 |
| B2 | **矛盾** | 两页对同一事实说法冲突 | 列出冲突点，标 `needs-verification` |
| B3 | **陈旧结论** | 被更新的原料覆盖 | 建议改 `status: superseded` 并指向替代页 |
| B4 | **重要概念缺页** | 被 ≥3 个页面以 `[[ ]]` 提及但无实体页 | 列入待补缺口（index.md 末节） |
| B5 | **缺失交叉引用** | A 提到 B 但未链 B | 建议补链 |
| B6 | `confidence: low` 长期未验证 | 超过 60 天 | 列出，建议要么验证要么降级归档 |
| B7 | **数据缺口** | 有页面留下"待补充/待验证"标记 | 建议一次外部检索补齐 |

## C. 报告格式

输出到 `wiki/00-总览/体检报告-YYYY-MM-DD.md`：

```markdown
# 体检报告 YYYY-MM-DD

## 概览
总页数 / 本次新增 / 自动修复数 / 待确认数

## 已自动修复
- [A3] 页面 X 的标签 `automation-test` → `automation-testing`

## 待你确认
### 矛盾
- [[页A]] 说 TPS 按 X 算，[[页B]] 说按 Y 算。哪个对？

### 孤页
- [[页C]] 无入链，建议挂到 [[页D]] 下？

## 建议的下一步投喂
- 缺「XXX」主题的页面，你手上有相关经验吗？
```

## D. 频率与触发

- 默认每周一次（见自动化任务）
- **A7 死链与孤页已做进构建脚本**（`build_kb.py`），每次构建都会报，不必等每周体检；死链会导致构建退出码为 1
- 单次 ingest 超过 10 个源后，建议手动补跑一次
- 连续两周无新增内容时，报告以「数据缺口 + 建议投喂主题」为主，避免空转
