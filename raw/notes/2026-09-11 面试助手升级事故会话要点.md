## 一、事故主线：示例代码被当成真 HTML 渲染

### 报障现象
用户：「访问页面加载遇到问题」。服务端全部正常（三文件 200、字节数正确、md5 与本地一致），JS 语法检查通过。

### 定位过程
1. **不靠猜，先复现**：无头 Chrome `--dump-dom` 渲染线上页面，发现 `#fatalFallback` 带 `class="show"` —— 全屏错误兜底面板盖在页面上，而底下内容其实渲染成功了
2. **抓不到 console 时的手法**：本地复制一份带插桩的 index.html，把全局 error 事件的 `type/target/src/msg` 写进 DOM，再 `--dump-dom` 读出来
3. 抓到的原始报错：
   ```
   type=error | target=IMG | src=https://bank.com/change_password?new_pass=attacker123 | msg=(空)
   ```
   `msg` 为空 + `target=IMG` → **资源加载失败**（不是脚本异常）

### 关键一跳：这个 URL 是哪来的？
是 CSRF 知识页里的一句**示例代码**：`<img src="https://bank.com/change_password?new_pass=attacker123">`。
它被当成了**真的 HTML** 渲染 → 浏览器真的去请求这个地址 → 请求失败 → 触发全局兜底面板。

### 为什么示例会被当真？
前一天为了修「代码块里的 `[[示例]]` 被误当双链」，用了**「整段替换成 Unicode 占位符 → markdown 转换 → 事后还原」**的写法。两层后果：
1. markdown 拿到占位符，**失去对代码内容转义与 `<code>` 包裹的机会**
2. 还原时把原始内容直接塞进 HTML —— 示例标签变成真标签

### 实际影响（比报错显示的大）
- **14/17 页**行内代码全部失效（正文残留裸反引号）
- **3 页**泄漏可执行 HTML：CSRF 的 `<img>`、CRLF 与 XSS 页的 `<script>alert(1)</script>`（**会真实执行**）
- 缺陷静默存在约 1 小时，直到一张图片加载失败才被顶出来

### 修法
换思路：**一次扫描的择一正则**（代码分支 | 双链分支），代码分支原样返回交给 markdown 正常转义，只对非代码分支做双链替换。
**并新增构建期不变量校验**：产物出现 `<script>/<img>/<iframe>/<form>/<svg>` 等标签即构建失败（退出码 1）—— 本渲染器不会产出这些标签，出现即是泄漏。

### 验证
真实浏览器（无头 Chrome）前后对比：兜底面板 弹出→未弹出；示例 HTML 原样注入→`&lt;img&gt;` 转义（原生标签 0 个）；裸反引号 14 页→0。

## 二、同一会话发现的其他问题

### 1. 筛选栏 9 天没渲染过
`renderChips` 内部 `$(containerId)` 传的是裸 id `"qChips"`，而 `$ = document.querySelector` 需要 `#` 前缀 → 查同名**标签**（不存在）→ null → `.innerHTML` 抛错 → **被 `safe()` 吞掉**。
站点自 09-02 上线起，题库/知识点/知识库三个页面的分类筛选栏从未出现。**静默失败，无任何报错。**

### 2. 11 条死链（存在了一整天）
入口页文件名 `题库索引.md`，标题「面试助手题库索引」。所有页面按**标题**写 `[[面试助手题库索引]]`，而链接按**文件名**解析 → 11 条链接全部静默失效。靠孤页/入链统计才暴露。

### 3. 部署推送了"半新半旧"的文件
首次部署后：线上 JS 是新的、但整个新增 CSS 块缺失（200926 vs 204950 字节）。这种状态在磁盘上从未存在过。重新部署一次后恢复（md5 与本地完全一致）。

### 4. 构建幂等缺陷
`kb.json` 的 `generatedAt` 每次构建都变 → 内容未变也产生 diff → 触发无意义的提交与线上重部署。修法：以 version（内容哈希）为判据，未变则跳过写入。

### 5. 全局 error 监听的过度反应
`window.addEventListener("error", fn, true)` 用了捕获模式，**资源加载失败也会触发**，导致一张图片 404 就弹全屏错误面板，把真实问题掩盖成"页面加载失败"。

## 三、方法论沉淀

1. **"占位符替换后还原"是破坏转义链路的反模式** —— 凡是要绕过解析器的处理，先问"还原时内容还会被转义吗"
2. **静默失败比报错更危险** —— 被 try/catch 吞掉的错误 + 不影响主内容 = 永远不会被发现（筛选栏活了 9 天）
3. **构建期校验要按不变量设计**（"渲染器不会产出 script 标签"），而不是逐个枚举已知问题类型
4. **无头浏览器 + 本地插桩副本**是前端问题的决定性定位手段，比读代码猜快得多
5. **部署后必须字节级核验**（md5 对比），不能只看 HTTP 200；缓存穿透要带 `?_v=`
