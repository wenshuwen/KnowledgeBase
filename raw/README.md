# raw/ — 原料层（不可变）

**这里的文件永不修改、永不删除。** 它是知识库的事实基准：wiki 里的每一句结论都应该能追溯到这里的某个文件（通过页面的 `sources` 字段）。

## 子目录

| 目录 | 放什么 |
|---|---|
| `inbox/` | **待编译暂存区**。自动抓取的内容先落这里，人工确认后才编译进 wiki。也可临时堆放你自己都还没想好怎么归类的材料 |
| `notes/` | 你手写的要点、口述记录的原始稿（不加工） |
| `files/` | docx、pdf、错误日志、测试报告、性能报告等原始文件 |
| `clippings/` | 网页剪藏转成的 markdown |
| `assets/` | 图片、截图等附件。**图片一律落盘**，wiki 页面不引用外部图床 |

## 命名建议

```
notes/    2026-09-10 性能瓶颈排查要点.md
files/    2026-09 某压测报告.docx          # 文件名里不要带项目真名
clippings/2026-09-10 某文章标题.md
```

## 红线

- 入库前必须脱敏：去掉项目名、产品名、真实域名与接口地址、账号、业务数据、客户信息
- 任何凭据（token / 密码 / 密钥）**不得**出现在本目录
- 超过 20MB 的大文件不纳入 Git（见根目录 `.gitignore`），但文件本身可以留在这里

## 注意

`inbox/` 不做长期存储。编译完成后原料应移动到对应子目录，`inbox/` 保持清空状态——它堆积起来就失去了「待办」的意义。
